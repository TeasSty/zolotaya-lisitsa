# Design concept — Золотая Лисица (Березники)

## Client / project

- Name: Золотая Лисица Салон Красоты Маникюр Березники
- Date: 2026-11-23
- Niche: локальный салон красоты (маникюр + парикмахерские + брови + детский мастер)
- Concept-ID: 2026-11-23-zolotaya-lisitsa-fox-den-editorial-v1
- Composition-archetype: full-bleed-editorial
- Forbidden-for-this-niche: quiet-luxury black/cream/gold UI; purple/indigo gradients; cream `#F4F1EA` + terracotta; broadsheet; hero + 3 equal feature-cards; fuchsia/blush Sevil-clone; diagonal-technical / product-theater / filmstrip-process carryover
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Ритуал: звонок/запись → кресло у зеркала → образ (стрижка / маникюр / брови) → тёплый разговор → уход
- Материалы: гель-лак и флаконы, ножницы, пеньюар, полотенце, лампа, зеркало, клиппер для детских стрижек
- Место / свет: 1 этаж, Советский пр-т 66 (центр, у Камня желания); тёплая лампа + блик лака на ногтях
- Жаргон: запись, покрытие, стрижка, окрашивание, плетение, детский мастер, акции ВТ–СР
- Сенсорика: глянец геля, запах лака, звук фена/ножниц, мягкое кресло
- Отличие: «свой образ / свой мастер» + отдельный мастер для маленьких гостей

## Unique thesis

1. Mood: тёплый «лисий зал» — уютный boutique-салон Березников, не megacorp spa и не quiet-luxury
2. Type rationale: острый display sans с «ухом лисы» в марке/букве + спокойный readable body (вывеска салона, не fashion-magazine serif)
3. Palette logic (from materials/light): russet/copper меха лисы, amber лака, lamp-ivory стен, mirror-pewter зеркала, ink; золото логотипа — только в марке, не палитра UI
4. Composition: full-bleed-editorial — один craft-кадр edge-to-edge; бренд = hero-signal громче headline
5. Motion: появление бренда, мягкий gloss-блик, сдвиг ленты работ (2–3 purposeful)
6. Main gesture: «ухо лисы» + full-bleed кадр рук/образа как якорь ниши

## Anti-clone checklist

- [x] Carryover: не Avtosvet diagonal-technical / Sandra product-theater / СНОВА НОВОЕ filmstrip — другая палитра, тип, скелет
- [x] Benchmark clone: Vanity Projects = craft bar (фото, иерархия, пейсинг), не ч/б+oxblood и не структура NYC/MIA
- [x] AI clusters: не purple-gradient / `#F4F1EA`+terracotta / broadsheet / dark SaaS / hero+3 cards
- [x] Brand test: без лого — руки+лак+детский кадр+местная запись = салон красоты, не юрист/пекарня/детейлинг
- [x] Quiet-luxury default: отклонено — russet/fox, не black/cream/metallic-gold UI

## Palette + type

- Palette:
  - `--fox-russet: #8B3A1F` — мех / акцент CTA
  - `--lacquer-amber: #C4782A` — тёплый лак / display
  - `--lamp-ivory: #F3E6D8` — свет стен / секции
  - `--mirror-pewter: #5C6368` — металл зеркала / muted
  - `--ink: #1E1714` — текст
  - `--berry-polish: #7A2E3A` — точечный акцент покрытия
  - `--hero-scrim: rgba(20, 12, 8, 0.55)` — читаемость на фото
- Type:
  - Display: Syne (геометрия + характер «лиса», не Inter/Playfair)
  - Body: Manrope (спокойная вывеска/меню салона)

## Site structure (one job per section)

1. Hero — бренд + один headline + support + CTA (запись / работы)
2. Работы — editorial strip портфолио
3. Услуги — меню/прайс как поверхность (не карточки-фичи)
4. Мастера — люди, не иконки
5. Детям — отдельный жест доверия для родителей
6. Запись / контакты — телефон, адрес, часы

## Photo approach

Close craft crops (руки, волосы, детский момент); тёплый lamp light; без стока «spa marble»; VK-материалы клиента приоритетны при наличии.
